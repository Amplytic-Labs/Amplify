# Frontend Design Skill

## Overview
This skill provides expert-level guidance for creating professional, production-ready frontend designs using modern web technologies.

## Guidelines

### Design Principles
- Use an 8px grid system for consistent spacing
- Ensure WCAG 2.1 AA accessibility (4.5:1 contrast ratio, keyboard navigation, ARIA labels)
- Design mobile-first, then scale up to tablet and desktop
- Use semantic HTML elements for better accessibility and SEO

### Color & Typography
- Use CSS custom properties for theming
- Limit to 2-3 fonts per project (heading + body)
- Ensure sufficient color contrast for text readability

### Component Design
- Include loading, empty, error, and success states
- Use progressive disclosure for complex interfaces
- Implement proper focus management for modals and dialogs

### Responsive Design
- Use CSS Grid and Flexbox for layouts
- Test at 3 breakpoints: mobile (375px), tablet (768px), desktop (1280px)
- Use relative units (rem, em, %) over fixed pixels
