# Cloud Providers

Amplify supports 19 cloud LLM providers. Each requires an API key (or configuration JSON) and offers both static and dynamic model discovery.

## OpenAI

| Property | Value |
|----------|-------|
| SDK | `@ai-sdk/openai` v4 |
| API Key | `OPENAI_API_KEY` |
| Get API Key | https://platform.openai.com/api-keys |
| Key Prefix | `sk-` |

### Available Models

| Model | Context Window | Max Output |
|-------|---------------|------------|
| GPT-4o | 128K | 4K (64K long output) |
| GPT-4o Mini | 128K | 4K |
| GPT-3.5 Turbo | 16K | 4K |
| o1-preview | 128K | 32K |
| o1-mini | 128K | 65K |

OpenAI supports dynamic model discovery — the full catalog is fetched from the API when you open the model selector.

## DeepSeek

| Get API Key | https://platform.deepseek.com/apiKeys |

| Model | Context Window | Max Output |
|-------|---------------|------------|
| DeepSeek-Coder | 8K | 8K |

DeepSeek is concurrency-limited (roughly 1 request per second). Repeated 429 errors can trigger an account-level cooldown lasting hours. Use conservative rate limits.

## OpenRouter

| Property | Value |
|----------|-------|
| SDK | `@openrouter/ai-sdk-provider` |
| API Key | `OPEN_ROUTER_API_KEY` |
| Get API Key | https://openrouter.ai/settings/keys |
| Key Prefix | `sk-or-` |

OpenRouter is a meta-provider that aggregates hundreds of models from multiple providers. It supports dynamic model discovery with pricing information for each model.

### Key Advantage

OpenRouter provides access to models you might not have direct API keys for, including free models. However, free-tier models have strict rate limits (20 RPM, 1000 RPD).

## GitHub Models

| Property | Value |
|----------|-------|
| SDK | `@ai-sdk/openai` (OpenAI-compatible) |
| API Key | `GITHUB_API_KEY` |
| Get API Key | https://github.com/settings/personal-access-tokens |
| Base URL | https://models.github.ai/inference |

GitHub Models provides access to major LLM providers through GitHub's unified API. Model IDs use the format `publisher/model-name` (e.g., `openai/gpt-4o`).

## Amazon Bedrock

| Property | Value |
|----------|-------|
| SDK | `@ai-sdk/amazon-bedrock` v5 |
| Config | `AWS_BEDROCK_CONFIG` |
| Get Config | https://console.aws.amazon.com/iam/home |

Amazon Bedrock uses a JSON configuration instead of a simple API key:

```bash
AWS_BEDROCK_CONFIG='{"region":"us-east-1","accessKeyId":"AKIA...","secretAccessKey":"wJalr...","sessionToken":"optional"}'
```

### Available Models

| Model | Context Window |
|-------|---------------|
| Claude 3.5 Sonnet v2 (Bedrock) | 200K |
| Claude 3.5 Sonnet (Bedrock) | 200K |
| Claude 3 Haiku (Bedrock) | 200K |

## Z.ai

| Property | Value |
|----------|-------|
| SDK | `@ai-sdk/openai` (custom) |
| API Key | `ZAI_API_KEY` |

Z.ai includes a custom fetch wrapper that transparently retries transient upstream errors (502, 503, 504) with exponential backoff and fallback base URLs. This handles the ALB intermittency that the z.ai endpoint can experience under load.
