# Workbench

The workbench is Amplify's integrated development environment that runs entirely in the browser. It combines a code editor, terminal, live preview, and file tree into a unified workspace powered by WebContainers.

## Workbench Layout

The workbench uses a panel-based layout with resizable sections:

- **Editor Panel** — CodeMirror 6 editor with syntax highlighting and multiple file tabs
- **Terminal Panel** — Full xterm.js terminal running inside the WebContainer
- **Preview Panel** — Live application preview with URL bar and port selection
- **File Tree** — Hierarchical file browser with icons and context menus
- **Search Panel** — Project-wide search and replace

The layout is managed by `Workbench.client.tsx`, which coordinates all panels and handles user interactions like file selection, terminal commands, and preview navigation.

## Code Editor

The editor is built on **CodeMirror 6** with extensive language support:

### Supported Languages

| Language | Extension |
|----------|-----------|
| JavaScript/TypeScript | `.js`, `.ts`, `.jsx`, `.tsx` |
| CSS/SASS | `.css`, `.scss`, `.sass` |
| HTML | `.html` |
| JSON | `.json` |
| Markdown | `.md`, `.mdx` |
| Python | `.py` |
| C/C++ | `.c`, `.cpp`, `.h` |
| Vue | `.vue` |
| WebAssembly | `.wast` |

### Editor Features

- **Syntax highlighting** — Language-specific highlighting via CodeMirror extensions
- **Auto-completion** — Context-aware autocomplete for supported languages
- **Search and replace** — In-file search with regex support
- **Indent detection** — Automatic indent style detection (tabs vs. spaces)
- **Environment masking** — Environment variable values are masked in `.env` files for security
- **Binary content** — Binary files display a placeholder instead of attempting text rendering
- **Custom theme** — Amplify-specific CodeMirror theme matching the app's design system

### Diff View

When the AI modifies files, the workbench shows a diff view highlighting:
- **Added lines** — Green background
- **Removed lines** — Red background
- **Modified sections** — Side-by-side comparison

The diff view uses the `DiffView` component with a custom diff algorithm that handles large files efficiently.

## Terminal

The terminal provides full command-line access inside the WebContainer:

### Terminal Features

- **Multiple tabs** — Run several terminal sessions simultaneously
- **Command history** — Previous commands are accessible with up-arrow navigation
- **Custom theme** — Amplify-branded terminal colors
- **Process management** — Terminal manager tracks running processes
- **Output capture** — Terminal output is captured and stored for AI context

### Common Operations

```bash
# Install dependencies
npm install

# Run development server
npm run dev

# Build for production
npm run build

# Run tests
npm test

# Git operations
git init
git add .
git commit -m "initial commit"
```

### Terminal Shortcuts

- **Ctrl+`** — Toggle terminal visibility
- **Ctrl+C** — Cancel running command
- **Ctrl+L** — Clear terminal output

## Live Preview

The preview panel shows your running application in an embedded iframe:

### Preview Features

- **Auto-refresh** — Preview updates automatically when files change
- **URL bar** — Navigate to specific paths within the preview
- **Port selector** — Switch between multiple running server ports
- **Error overlay** — Runtime errors appear as overlay alerts
- **Inspector script** — Preview errors are forwarded to the workbench alert system

### Preview Error Handling

The WebContainer forwards preview errors (uncaught exceptions, unhandled promise rejections) to the workbench:
1. Error detected in preview iframe
2. `webcontainer.on('preview-message')` captures the error
3. `workbenchStore.actionAlert.set()` displays the error
4. Error details include stack trace, URL, and port information

## File Tree

The file tree provides a hierarchical view of all project files:

### File Tree Features

- **File icons** — Language-specific icons for recognized file types
- **Folder expansion** — Expand/collapse directories
- **Context menu** — Right-click for file operations (rename, delete, etc.)
- **Search** — Filter files by name
- **Modified indicators** — Highlight recently changed files
- **Lock indicators** — Show files that are locked (being edited by AI)

### File Locking

When the AI is modifying a file, it becomes "locked" to prevent concurrent edits:
- Locked files show a visual indicator in the file tree
- The `LockManager` component handles lock/unlock operations
- Locks are automatically released when the AI finishes its modifications

## Artifact Rendering

The workbench supports rendering various artifact types beyond code:

- **HTML artifacts** — Rendered as live HTML previews
- **DOCX artifacts** — Previewed in the DocxPreviewPanel
- **Mermaid diagrams** — Rendered as SVG diagrams
- **Charts** — Rendered as interactive chart visualizations

The `ArtifactRenderer` dispatches to appropriate renderers based on the artifact type.

## Deployment

The workbench includes deployment integration for several platforms:

### Vercel Deployment

1. Connect your Vercel account via the Settings panel
2. Click **Deploy** in the workbench header
3. The project is built and deployed to Vercel
4. A deployment link appears in the chat

### Netlify Deployment

1. Connect your Netlify account
2. Deploy directly from the workbench
3. Netlify provides a live URL for the deployed site

### GitHub / GitLab Deployment

1. Push to a connected repository
2. The deployment dialog shows branch and repository options
3. CI/CD pipeline handles the deployment

## Screenshot Capture

The `ScreenshotSelector` component allows capturing screenshots:
- **Viewport screenshot** — Capture the current preview
- **Full-page screenshot** — Capture the entire preview page
- **Area selection** — Select a specific region to capture
- **Clipboard paste** — Paste screenshots from the clipboard

Screenshots can be sent to the AI as visual context for debugging or design feedback.

## Port Management

The `PortDropdown` component shows all active WebContainer server ports:
- Automatically detects when a server starts on a new port
- Lists all available ports with their status
- Allows switching between ports for the preview

## Expo QR Code

For React Native / Expo projects, the `ExpoQrModal` component displays:
- QR code for mobile device connection
- Expo development server URL
- Connection status and tunnel information
