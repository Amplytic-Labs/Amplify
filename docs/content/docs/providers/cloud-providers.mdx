Amplify supports 19 cloud AI providers. Each one requires an API key (or equivalent credentials) set either in the UI settings dialog or as an environment variable. This page covers configuration details for every cloud provider.

## Anthropic

**Environment variable:** `ANTHROPIC_API_KEY`
**Get API key:** [console.anthropic.com/settings/keys](https://console.anthropic.com/settings/keys)

Anthropic provides the Claude family of models, known for strong reasoning and coding capabilities.

| Model | Context Window | Max Output | Notes |
|-------|---------------|------------|-------|
| `claude-3-5-sonnet-20241022` | 200,000 | 128,000 | Best balance of speed and intelligence |
| `claude-3-haiku-20240307` | 200,000 | 128,000 | Fastest, most cost-effective |
| `claude-opus-4-20250514` | 200,000 | 32,000 | Latest flagship, deepest reasoning |

**Special features:**
- Dynamic model discovery via Anthropic's `/v1/models` endpoint
- `anthropic-beta: output-128k-2025-02-19` header enabled for extended output
- Context window detection based on model ID heuristics

## Amazon Bedrock

**Environment variable:** `AWS_BEDROCK_CONFIG` (JSON string, not a plain API key)
**Get API key:** [console.aws.amazon.com/iam/home](https://console.aws.amazon.com/iam/home)

Amazon Bedrock provides managed access to foundation models from multiple providers.

**Configuration format:**
```json
{
  "region": "us-east-1",
  "accessKeyId": "AKIAIOSFODNN7EXAMPLE",
  "secretAccessKey": "wJalrXUtnFEMI/K7MDENG/bPxRfiCYEXAMPLEKEY",
  "sessionToken": "optional-session-token"
}
```

| Model | Context Window | Notes |
|-------|---------------|-------|
| `anthropic.claude-3-5-sonnet-20241022-v2:0` | 200,000 | Claude 3.5 Sonnet v2 |
| `anthropic.claude-3-haiku-20240307-v1:0` | 4,096 | Claude 3 Haiku |
| `amazon.nova-pro-v1:0` | 5,120 | Amazon Nova Pro |
| `mistral.mistral-large-2402-v1:0` | 8,192 | Mistral Large |

**Special features:**
- Requires a JSON configuration object (not a simple API key)
- The JSON must include `region`, `accessKeyId`, and `secretAccessKey`
- Optional `sessionToken` for temporary credentials
- Uses the dedicated `@ai-sdk/amazon-bedrock` package
- Static models only (no dynamic discovery)

## Z.AI

**Environment variable:** `ZAI_API_KEY`
**Get API key:** [open.bigmodel.cn/usercenter/apikeys](https://open.bigmodel.cn/usercenter/apikeys)

Z.AI (formerly BigModel/GLM) provides Chinese-developed GLM models with strong coding capabilities.

| Model | Context Window | Max Output | Notes |
|-------|---------------|------------|-------|
| `glm-4.6` | 200,000 | 65,536 | Flagship coding model |
| `glm-4.7-flash` | 128,000 | 65,536 | Fast variant |
| `glm-4.5` | 128,000 | 65,536 | General purpose |
| `glm-4.5-flash` | 128,000 | 65,536 | Fast general purpose |

**Special features:**
- **Automatic retry with fallback** — Transient 502/503/504 errors from z.ai's ALB are transparently retried (up to 4 retries with exponential backoff)
- **Endpoint fallback** — Automatically falls back from the Coding Plan endpoint (`/api/coding/paas/v4`) to the standard endpoint (`/api/paas/v4`) if the Coding Plan tier is down
- **Dual authentication** — Supports plain Bearer tokens (default) and JWT signing via `ZAI_AUTH_MODE=jwt` for legacy BigModel keys
- Dynamic model discovery from z.ai `/models` endpoint
- Default base URL: `https://api.z.ai/api/coding/paas/v4`
