# Chat

Amplify's chat interface is a full-featured, multi-model conversation environment designed for both casual prompts and complex coding tasks. It goes far beyond a simple text box — integrating tool invocation, artifact rendering, reasoning display, voice input, and context management into a single cohesive experience.

## Multi-Model Chat

Amplify supports 20+ LLM providers including OpenAI, Anthropic, Google, Mistral, Deepseek, Groq, Cerebras, Together, Fireworks, Cohere, Ollama, LM Studio, Open Router, HuggingFace, Amazon Bedrock, xAI, Moonshot, Hyperbolic, Z-AI, and custom OpenAI-compatible endpoints.

The **model selector** appears next to every prompt, allowing you to pick a different model for each individual message. This means you can use a fast model like Groq for quick questions and switch to Claude or GPT-4 for complex reasoning — without changing any global setting.

Each provider can be configured with its own API key, base URL, and model list. Local providers (Ollama, LM Studio) are supported with health monitoring and automatic detection.

## Streaming AI Responses

All responses stream in real-time using the Vercel AI SDK's streaming protocol. You see tokens arrive character-by-character, with rich formatting applied as the response renders — including code blocks, tables, lists, and inline markup.

The streaming pipeline includes:

- **Smooth rendering** — tokens are buffered and rendered with easing animations to avoid visual jitter
- **Incremental parsing** — markdown, code blocks, and tool invocations are parsed as they arrive
- **Summarization** — when the context budget approaches its limit, older messages are automatically condensed to preserve the conversation without losing key information

## Tool Invocation

When the AI decides to use a tool (native tools, MCP tools, or the `execute_plan` tool), the invocation appears inline in the conversation with a dedicated UI:

- **Read-only tools** (`read_file`, `list_dir`, `find_files`, `grep_search`, `web_search`) auto-execute without requiring approval
- **Mutating tools** (`replace_string_in_file`, `multi_replace_string_in_file`, `create_file`) display an **Approve / Deny** dialog before execution
- Tool results are rendered with contextual formatting — file contents show line numbers, search results are highlighted, and mutations show diff previews

This mirrors VSCode Copilot's approach: the AI can freely read your workspace, but every file edit requires your explicit consent.

## Artifact Rendering

The AI can produce artifacts — standalone renderable outputs embedded in the conversation:

- **HTML artifacts** render inline with a live preview panel, including full CSS and JavaScript
- **DOCX artifacts** are rendered using a custom preview panel that converts the document to a readable format with proper formatting, tables, and styles
- Artifacts can be opened in the workbench for further editing

The artifact system uses a dedicated stripper pipeline that separates artifact content from the main response, ensuring clean conversation flow.

## Reasoning / Thinking Display

Models that emit reasoning tokens (such as Deepseek's "thinking" mode or Claude's extended thinking) display their reasoning process in a collapsible panel:

- Reasoning blocks are parsed from `<think>` tags or dedicated reasoning fields
- They appear as a separate "Thinking" section above the final answer
- The panel can be expanded or collapsed to focus on the reasoning or the conclusion

This gives you transparency into the AI's decision-making process, especially valuable for complex debugging or architectural decisions.

## Voice Prompting

Amplify includes a speech-to-text input option using the browser's **SpeechRecognition API**:

- Click the microphone icon in the chat input bar to start voice input
- The browser transcribes your speech in real-time and populates the input field
- Click again to stop recording
- Works in Chrome, Edge, and Safari (requires browser permission for microphone access)

No external API keys are needed — voice recognition runs entirely in the browser.

## Prompt Enhancer

The **Enhance** button next to the input field sends your draft prompt to the AI for improvement before submission:

1. You type a rough prompt (e.g., "make a login page")
2. Click the Enhance button (sparkle icon)
3. The enhancer API rewrites it into a detailed, specific prompt
4. The enhanced text replaces your input, ready for submission

This is especially useful when you have a general idea but want the AI to understand your intent more precisely. The enhancer uses the same model you've selected for the conversation.

## Chat Export / Import

Amplify supports full conversation export and import:

- **Export** — download all chats as a ZIP file containing structured JSON data with full message history, metadata, and timestamps
- **Import** — upload a previously exported ZIP to restore conversations
- The `ImportExportService` sanitizes messages during export, ensuring compatibility across versions
- Chat descriptions and metadata are preserved

This makes it easy to backup your work, share conversations, or migrate between devices.

## Chat Modes

Amplify supports multiple chat interaction modes:

- **Build mode** — the AI actively writes code, creates files, and modifies your workspace using native tools
- **Discuss mode** — a focused conversation mode where the AI answers questions, explains concepts, and provides guidance without modifying files
- Each mode uses a different system prompt tailored to the interaction style

The mode is selectable per conversation, allowing you to switch between active development and knowledge-seeking as needed.

## Message Rewind / Fork

Conversations support rewind and fork operations for exploring different paths:

- **Rewind** — roll back the conversation to a previous message, discarding subsequent messages
- **Fork** — branch from a specific message, creating an alternative conversation path
- This lets you explore "what if" scenarios without losing your original conversation

Both operations are accessible from the message UI, giving you fine-grained control over the conversation history.

## Context Budget Indicator

The **Context Budget Indicator** is a live pill in the chat input bar showing how much of the current model's context window is being consumed:

- **Color coding**: green (under 50%), amber (50–75%), orange (75–90%), red (over 90%)
- Click the pill to open a detailed popover showing:
  - Model name and context window size
  - Tokens used and remaining
  - The summarization trigger threshold (70% of usable budget)
  - A visual progress bar with zone markers
  - Workspace file count
- When over 70%, the status dot pulses to draw attention
- When the trigger is reached, older messages are automatically summarized to preserve context

This transparency helps you understand why summarization happens and plan your conversations accordingly.
