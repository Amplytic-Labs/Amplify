# Design Systems

Amplify bundles **100+ design system references** that the AI can use to create professional, brand-aligned UIs. Each design system comes with a detailed `DESIGN.md` file containing visual guidelines — color palettes, typography rules, spacing systems, component patterns, and atmospheric descriptions.

## What Are Design Systems?

A design system in Amplify is a structured reference document that teaches the AI how to replicate a specific visual style. It's not a CSS framework or a component library — it's a **knowledge base** that the AI reads and applies when generating UI code.

Each `DESIGN.md` includes:

- **Visual Theme & Atmosphere** — a detailed description of the design's feel and character
- **Color Palette & Roles** — primary, secondary, accent, background, and semantic colors with hex values and usage rules
- **Typography System** — font families, size scales, weight rules, letter-spacing, and line-height guidelines
- **Spacing & Layout** — grid systems, padding/margin scales, and layout patterns
- **Shadow & Elevation** — multi-layer shadow systems, border-radius rules, and depth hierarchy
- **Component Patterns** — how buttons, cards, inputs, navigation, and other components look in this style
- **Animation & Interaction** — transition timing, hover states, and micro-interactions

## How to Browse and Use Design Systems

Design systems are accessible in two ways:

### In Chat

When you tell the AI to create a UI, mention a design system by name:

- "Create a landing page using the Stripe design system"
- "Build a dashboard inspired by Linear"
- "Make a portfolio page with the Minimal design system"

The AI reads the corresponding `DESIGN.md` and applies its guidelines to the generated code.

### In Settings

The **Design Systems** section in settings shows all available systems organized by category. You can browse, preview summaries, and set a default design system for your project.

## Design System Structure

Each design system directory contains a `DESIGN.md` file with this structure:

```markdown
# Design System Inspired by [Name]

> Category: [Category]
> [Summary description]

## 1. Visual Theme & Atmosphere
## 2. Color Palette & Roles
## 3. Typography System
## 4. Spacing & Layout
## 5. Shadow & Elevation
## 6. Component Patterns
## 7. Animation & Interaction
## 8. CSS Custom Properties (ready-to-use variables)
```

The final section provides CSS custom properties that the AI can directly inject into generated components, making the design system immediately applicable.
