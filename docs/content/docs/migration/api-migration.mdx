Amplify isn't just a web application — it's a collection of modular components that can be extracted and reused independently. This guide covers how to decouple Amplify's core capabilities and integrate them into your own applications.

## Understanding the API Structure

Amplify is built on Remix, a full-stack React framework where server-side logic lives in route modules. Each route can define:

- **Loader functions** — Server-side data fetching (GET requests)
- **Action functions** — Server-side mutations (POST requests)
- **API routes** — Pure JSON endpoints without UI rendering

```text
┌──────────────────────────────────────────────────────────────┐
│                     Amplify Remix App                         │
│                                                              │
│  ┌─────────────┐  ┌──────────────┐  ┌─────────────────────┐ │
│  │ Chat API    │  │ MCP Service  │  │ Vector Store        │ │
│  │ /api/chat   │  │ /api/mcp     │  │ /api/vector         │ │
│  └─────────────┘  └──────────────┘  └─────────────────────┘ │
│                                                              │
│  ┌─────────────┐  ┌──────────────┐  ┌─────────────────────┐ │
│  │ AI Provider │  │ Git API      │  │ Project API         │ │
│  │ System      │  │ /api/git     │  │ /api/project        │ │
```

## Key API Endpoints and Their Purposes

### Chat API (`/api/chat`)

The core AI interaction endpoint. Handles streaming chat completions using the AI SDK:

- **Input**: User message, model selection, provider configuration
- **Output**: Streaming text responses via Server-Sent Events (SSE)
- **Features**: Multi-model support, context management, tool calls

### MCP Service (`/api/mcp`)

Model Context Protocol service for tool integration:

- **Purpose**: Standardized tool interface for AI agents
- **Features**: Tool discovery, invocation, and result handling
- **Protocol**: JSON-RPC based, compatible with MCP specification

### Vector Store (`/api/vector`)

Embedding storage and semantic search using Orama:

- **Purpose**: Code and document search, context retrieval
- **Features**: Indexing, querying, relevance scoring
- **Storage**: In-memory with optional persistence

### Git API (`/api/git`)

Repository operations using isomorphic-git and Octokit:

- **Purpose**: Clone, branch, commit, push operations
- **Features**: GitHub/GitLab integration, repository management

### Project API (`/api/project`)

Project lifecycle management:

- **Purpose**: Create, read, update, delete projects
- **Features**: File operations, project settings, export/import

### Standalone LLM Pipeline Example

Extract the chat pipeline into a standalone Express server:

```typescript
// server.ts — Custom backend using Amplify's AI pipeline
import express from 'express';
import { streamText } from 'ai';
import { createOpenAI } from '@ai-sdk/openai';
import { createAnthropic } from '@ai-sdk/anthropic';

const app = express();
app.use(express.json());

// Provider factory — matches Amplify's provider selection logic
function getProvider(providerName: string, apiKey: string) {
  switch (providerName) {
    case 'openai':
      return createOpenAI({ apiKey });
    case 'anthropic':
      return createAnthropic({ apiKey });
    // Add more providers as needed
    default:
      throw new Error(`Unknown provider: ${providerName}`);
  }
}

// Chat endpoint — mirrors Amplify's /api/chat
app.post('/api/chat', async (req, res) => {
  const { messages, provider, model, apiKey } = req.body;

  try {
    const providerInstance = getProvider(provider, apiKey);
    const modelInstance = providerInstance(model);

    const result = streamText({
      model: modelInstance,
      messages,
    });

    // Stream the response as SSE (same format as Amplify)
    result.toDataStreamResponse().pipeTo(
      new WritableStream({
        write(chunk) {
          res.write(chunk);
        },
        close() {
          res.end();
        },
      })
    );
  } catch (error) {
    res.status(500).json({ error: error.message });
  }
});

app.listen(3000, () => {
  console.log('Custom AI server running on port 3000');
});
```

## Building a Custom Backend Using the AI SDK

### Express-Based Backend

```typescript
import express from 'express';
import { streamText, generateText, tool } from 'ai';
import { z } from 'zod';
import { createOpenAI } from '@ai-sdk/openai';

const app = express();
app.use(express.json());

const openai = createOpenAI({
  apiKey: process.env.OPENAI_API_KEY,
});

// Streaming chat endpoint
app.post('/chat', async (req, res) => {
  const { messages } = req.body;

  const result = streamText({
    model: openai('gpt-4o'),
    messages,
    tools: {
      // Custom tools — similar to Amplify's MCP tools
      search: tool({
        description: 'Search the web for information',
        parameters: z.object({ query: z.string() }),
        execute: async ({ query }) => {
          // Your search implementation
          return { results: [] };
        },
      }),
    },
  });

  for await (const chunk of result.fullStream) {
    res.write(JSON.stringify(chunk) + '\n');
  }
  res.end();
});

// Non-streaming endpoint for simpler use cases
app.post('/generate', async (req, res) => {
  const { prompt } = req.body;

  const result = await generateText({
    model: openai('gpt-4o'),
    prompt,
  });

  res.json({ text: result.text });
});

app.listen(3000);
```

### Fastify-Based Backend

```typescript
import Fastify from 'fastify';
import { streamText } from 'ai';
import { createAnthropic } from '@ai-sdk/anthropic';

const fastify = Fastify({ logger: true });

const anthropic = createAnthropic({
  apiKey: process.env.ANTHROPIC_API_KEY,
});

fastify.post('/chat', async (request, reply) => {
  const { messages } = request.body;

  const result = streamText({
    model: anthropic('claude-sonnet-4-20250514'),
    messages,
  });

  reply.raw.writeHead(200, {
    'Content-Type': 'text/event-stream',
    'Cache-Control': 'no-cache',
    Connection: 'keep-alive',
  });

  for await (const chunk of result.textStream) {
    reply.raw.write(`data: ${JSON.stringify({ text: chunk })}\n\n`);
  }

  reply.raw.end();
});

fastify.listen({ port: 3000 });
```

## Replacing Remix Routes with Other Frameworks

Amplify uses Remix for its server layer. If you prefer a different framework, you can extract the business logic and adapt it:

### Route Mapping

| Remix Concept | Express Equivalent | Fastify Equivalent |
| --- | --- | --- |
| `loader` (GET) | `app.get('/path', handler)` | `fastify.get('/path', handler)` |
| `action` (POST) | `app.post('/path', handler)` | `fastify.post('/path', handler)` |
| `LoaderArgs.context` | Middleware injected context | Plugin-based context |
| `json()` response | `res.json()` | `reply.send()` |
| `streamText()` SSE | Manual SSE handling | Manual SSE handling |

### Extracting Business Logic

The key is to keep the business logic (AI calls, data processing, MCP interactions) separate from the framework-specific routing:

```typescript
// chat-service.ts — Framework-independent business logic
import { streamText } from 'ai';
import { getProviderByName } from './providers';

export async function handleChatRequest(params: {
  messages: Message[];
  provider: string;
  model: string;
}) {
  const provider = getProviderByName(params.provider);
  const modelInstance = provider(params.model);

  return streamText({
    model: modelInstance,
    messages: params.messages,
  });
}

// Express adapter
import express from 'express';
import { handleChatRequest } from './chat-service';

app.post('/api/chat', async (req, res) => {
  const result = await handleChatRequest(req.body);
  // Stream response...
});

// Fastify adapter
import Fastify from 'fastify';
import { handleChatRequest } from './chat-service';

fastify.post('/api/chat', async (request, reply) => {
  const result = await handleChatRequest(request.body);
  // Stream response...
});
```

## Porting the MCP Service to Other Runtimes

Amplify's MCP (Model Context Protocol) service can be extracted for use in any Node.js runtime.

### MCP Service Architecture

```text
┌────────────────────────────────────────────┐
│              MCP Service                    │
│                                             │
│  ┌──────────┐  ┌──────────┐  ┌──────────┐ │
│  │ Tool     │  │ Resource │  │ Transport │ │
│  │ Registry │  │ Manager  │  │ Layer     │ │
│  └──────────┘  └──────────┘  └──────────┘ │
│                                             │
│  ┌──────────────────────────────────────┐   │
│  │ @modelcontextprotocol/sdk            │   │
│  │ JSON-RPC protocol implementation     │   │
│  └────────────────────────────────────┘   │
└────────────────────────────────────────────┘
```

### Standalone MCP Server

```typescript
// mcp-server.ts — Standalone MCP service
import { Server } from '@modelcontextprotocol/sdk/server/index.js';
import { StdioServerTransport } from '@modelcontextprotocol/sdk/server/stdio.js';

const server = new Server(
  { name: 'amplify-mcp', version: '1.0.0' },
  { capabilities: { tools: {} } }
);

// Register tools (port from Amplify's tool definitions)
server.setRequestHandler('tools/list', async () => ({
  tools: [
    {
      name: 'execute_code',
      description: 'Execute code in a sandboxed environment',
      inputSchema: {
        type: 'object',
        properties: {
          code: { type: 'string' },
          language: { type: 'string' },
        },
      },
    },
    {
      name: 'search_docs',
      description: 'Search documentation using vector store',
      inputSchema: {
        type: 'object',
        properties: {
          query: { type: 'string' },
        },
      },
    },
  ],
}));

server.setRequestHandler('tools/call', async (request) => {
  const { name, arguments: args } = request.params;

  switch (name) {
    case 'execute_code':
      // Your code execution implementation
      return { content: [{ type: 'text', text: 'Execution result' }] };
    case 'search_docs':
      // Your search implementation
      return { content: [{ type: 'text', text: 'Search results' }] };
    default:
      throw new Error(`Unknown tool: ${name}`);
  }
});

// Start the server
const transport = new StdioServerTransport();
await server.connect(transport);
```

### HTTP Transport (for Web Access)

For browser-based access, use the SSE transport instead of stdio:

```typescript
import { SSEServerTransport } from '@modelcontextprotocol/sdk/server/sse.js';

// Express integration
app.get('/mcp/sse', (req, res) => {
  const transport = new SSEServerTransport('/mcp/messages', res);
  server.connect(transport);
});

app.post('/mcp/messages', (req, res) => {
  // Handle MCP messages via HTTP
  transport.handlePostMessage(req, res);
});
```

## Using the Vector Store in Standalone Applications

Amplify uses Orama for in-memory vector search and document indexing. You can use Orama independently:

### Standalone Orama Setup

```typescript
import { create, insert, search } from '@orama/orama';

// Create an Orama database (same as Amplify's vector store)
const db = await create({
  schema: {
    id: 'string',
    content: 'string',
    embedding: 'vector[1536]',   // OpenAI embedding dimension
    metadata: 'string',
    timestamp: 'number',
  },
});

// Insert documents
await insert(db, {
  id: 'doc-1',
  content: 'Documentation about API endpoints',
  embedding: [0.1, 0.2, 0.3, /* ...1536 dimensions */],
  metadata: '{"source": "docs", "category": "api"}',
  timestamp: Date.now(),
});

// Search with vector similarity
const results = await search(db, {
  vector: {
    value: [0.15, 0.25, 0.35, /* ...query embedding */],
    property: 'embedding',
  },
  limit: 10,
  similarity: 0.8,
});

console.log(results.hits);
```

### Integration with AI Pipeline

Combine Orama search with the AI SDK for context-augmented generation:

```typescript
import { streamText } from 'ai';
import { search } from '@orama/orama';

async function ragChat(query: string, db: OramaDb) {
  // Get query embedding from your embedding provider
  const queryEmbedding = await getEmbedding(query);

  // Search relevant documents
  const searchResults = await search(db, {
    vector: {
      value: queryEmbedding,
      property: 'embedding',
    },
    limit: 5,
  });

  // Build context from search results
  const context = searchResults.hits
    .map((hit) => hit.document.content)
    .join('\n\n');

  // Generate response with context
  return streamText({
    model: openai('gpt-4o'),
    system: `Use the following context to answer questions:\n${context}`,
    prompt: query,
  });
}
```

## Embedding Amplify's Chat in Other Applications

You can embed Amplify's chat interface into other web applications without deploying the full Amplify application.

### Option 1: iframe Embedding

The simplest approach — embed the full Amplify interface in an iframe:

```html
<iframe
  src="https://your-amplify-instance.com"
  width="100%"
  height="600"
  style="border: none;"
  sandbox="allow-scripts allow-same-origin allow-forms"
></iframe>
```

### Option 2: Extract the Chat Component

Amplify's chat UI is built with React and can be extracted as a standalone component:

```typescript
// Extract the chat component and its dependencies:
// - Chat UI component
// - AI SDK React hooks (@ai-sdk/react)
// - Message types and serialization
// - Streaming SSE client

import { useChat } from '@ai-sdk/react';

function EmbeddedChat() {
  const { messages, input, handleInputChange, handleSubmit } = useChat({
    api: 'https://your-amplify-instance.com/api/chat',
  });

  return (
    <div className="embedded-chat">
      {messages.map((msg) => (
        <div key={msg.id} className={msg.role}>
          {msg.content}
        </div>
      ))}
      <form onSubmit={handleSubmit}>
        <input value={input} onChange={handleInputChange} />
        <button type="submit">Send</button>
      </form>
    </div>
  );
}
```

### Option 3: API-Only Integration

For non-React applications, use Amplify's chat API directly:

```javascript
// Vanilla JavaScript SSE client for Amplify's chat API
async function streamChat(messages) {
  const response = await fetch('https://your-amplify-instance.com/api/chat', {
    method: 'POST',
    headers: { 'Content-Type': 'application/json' },
    body: JSON.stringify({ messages }),
  });

  const reader = response.body.getReader();
  const decoder = new TextDecoder();

  while (true) {
    const { done, value } = await reader.read();
    if (done) break;

    const chunk = decoder.decode(value);
    // Parse SSE data and display in your UI
    process.stdout.write(chunk);
  }
}
```

### Option 4: Headless API Integration

For complete custom UIs, call Amplify's endpoints programmatically:

```python
# Python client for Amplify's API
import requests
import json

AMPLIFY_URL = "https://your-amplify-instance.com"

def chat(messages, model="gpt-4o"):
    response = requests.post(
        f"{AMPLIFY_URL}/api/chat",
        json={"messages": messages, "model": model},
        stream=True
    )

    for line in response.iter_lines():
        if line:
            data = json.loads(line)
            yield data

# Usage
for chunk in chat([{"role": "user", "content": "Hello!"}]):
    print(chunk)
```

## Migration Checklist

When extracting Amplify components for custom applications:

1. **Identify needed components** — Which APIs and services do you need?
2. **Install dependencies** — Add the required `ai` SDK packages and provider modules
3. **Extract business logic** — Separate framework-specific code from core logic
4. **Set up provider configuration** — Configure API keys and provider selection
5. **Implement transport layer** — Set up SSE streaming for chat responses
6. **Configure MCP tools** — Register the tools your application needs
7. **Set up vector store** — Create Orama databases for your data
8. **Test integration** — Verify each extracted component works independently
9. **Deploy** — Use your preferred deployment method
10. **Monitor** — Set up logging and metrics for your custom backend
