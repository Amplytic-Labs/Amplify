## What is Amplify?

Amplify is an open-source, AI-powered coding environment that brings together the best of modern web development and artificial intelligence. Built on **Remix v2** with the **Vercel AI SDK v7**, Amplify provides a full-featured IDE-like experience in the browser — complete with intelligent code generation, contextual understanding, and a rich ecosystem of integrations.

Whether you're prototyping a new idea, exploring a codebase, or building production-grade applications, Amplify gives you the tools to code faster, smarter, and with greater confidence.

## Key Features

Amplify ships with a comprehensive set of capabilities designed to supercharge your development workflow:

### 22+ AI Providers

Connect to over **22 LLM providers** including OpenAI, Anthropic, Google, Mistral, Cohere, and more. Switch between providers seamlessly or use multiple models simultaneously for different tasks. Amplify's provider abstraction ensures a consistent interface regardless of which model you choose.

### MCP Support

Full support for the **Model Context Protocol (MCP)** enables Amplify to interact with external tools, data sources, and services through a standardized protocol. Connect databases, APIs, custom tooling, and third-party services — all through MCP's extensible architecture.

### Vector DB with Orama

Built-in **vector search** powered by Orama gives Amplify persistent semantic memory. Index your codebase, documentation, and conversation history for instant retrieval of relevant context. Orama's lightweight, in-browser engine means zero external dependencies for search.

### WebContainer Sandboxing

Amplify runs user code safely inside **WebContainers** — a browser-based sandbox that provides a full Node.js runtime without server-side execution. Preview applications, run scripts, and test changes in real-time, all within a secure, isolated environment.

### Planning System

Amplify's **Planning system** breaks complex tasks into structured, step-by-step execution plans. Before writing a single line of code, the AI outlines its approach — giving you visibility, control, and the ability to refine the plan before implementation begins.

### Memory System

The **Memory system** provides persistent context across sessions. Amplify remembers your preferences, past decisions, project conventions, and ongoing work — so every conversation starts with the context it needs, not from scratch.

### Native Tools

A suite of **native tools** for file operations, shell commands, code editing, web browsing, and more. These built-in capabilities let Amplify interact directly with your project environment — reading files, running commands, making edits, and verifying results end-to-end.

### 100+ Design Systems

Access over **100 design systems** and component libraries out of the box. From Material UI to shadcn/ui, Tailwind CSS to Radix, Amplify integrates with the ecosystem you already know — making it effortless to generate UI code that matches your project's design language.

### Skills Marketplace

The **Skills marketplace** lets you discover, install, and share specialized AI capabilities. Skills are modular, composable units that extend Amplify's behavior — from domain-specific code generators to workflow automations and custom integrations.

## Architecture Overview

Amplify is built on a modern, production-grade stack:

- **Remix v2** — Full-stack web framework with server-side rendering and progressive enhancement
- **Vercel AI SDK v7** — Streaming AI responses, multi-provider support, and tool orchestration
- **WebContainers** — Browser-based Node.js runtime for safe code execution
- **Orama** — Embedded vector search engine for semantic retrieval
- **MCP** — Standardized protocol for external tool integration

Head over to [Architecture](/docs/architecture) for a deep dive into how these pieces fit together.
